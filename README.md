# Triagem de atendimento

Projeto demonstrativo de automação de triagem. Recebe uma mensagem, identifica uma categoria e encaminha para uma fila de atendimento.

## Executar

```bash
python app.py "Meu boleto não chegou"
```

## Categorias

- `vendas`
- `suporte`
- `financeiro`
- `outros`

O projeto usa dados fictícios e não é um atendimento real.
